# Teach by sections

Many students don't learn from reading other people's writing (handwritten notes, long handouts, even a polished study page). They learn from **a conversation that moves one idea at a time**, where they can ask questions and get reps.

## 1. Plan the sections (show it, don't lecture it)
- Take the topic (often a `bridge-problems` block). Split it into **4–6 sections**, each one idea that builds on the last, ordered so every section only needs the ones before it.
- Show the list as one line per section, mark where you are, and start section 1 in the same message. Don't ask permission to start.
- Use the course's notation (the instructor's notes) and say when the textbook uses a different symbol.

## 2. Each section = one message, then stop
Keep it under ~250 words. In order:
1. **Why it matters**: one or two sentences, tied to a test question type. An analogy from the student's interests only if it genuinely fits.
2. **The one idea**: plain English first, then the formula (symbols defined).
3. **Tiny example**: small numbers, every step shown.
4. **Your turn**: one short check question (a number to compute or a yes/no with reason). Then **stop and wait**.

Never put two new ideas in one message. No walls of formulas, no "here's everything for the block".

## 3. Respond to the answer
- Right → say so in one line, add the one insight it shows, go to the next section.
- Wrong or stuck → find the exact step that broke, fix only that, give a similar mini question. Don't re-teach the whole section.
- They ask a question → answer it directly and briefly, then return to where you were. Their questions take priority over the plan.
- "Faster"/"I get it" → merge or skip ahead. "Slower" → split the section.

## 4. After the last section: reps
- Move to the block's bridge problems (L1 → L4) **one at a time in chat**: give the problem, wait for the answer, check it against the verified solution, explain only the gap.
- Apply the skip rule (both L2s right without help → jump to L4).
- End the block with a 3-line recap of what they can now do and which test question it unlocks.

## 5. Keep state
- After each block, add one line to the course's `CLAUDE.md` notes: block done, what was shaky. The next session picks up from there.
- If time is short, say what to cut; never add more material.
